# College Management SQL Analysis Project

## Project Overview

This project demonstrates SQL analysis on a College Management System database.

The database contains information about:

* Students
* Courses
* Enrollments
* Exams

The goal of the project is to perform real-world data analysis using SQL queries and gain hands-on experience with database operations.

---

## Database Structure

### Students

* student_id
* student_name
* city
* age

### Courses

* course_id
* course_name
* fees

### Enrollments

* enrollment_id
* student_id
* course_id
* enrollment_date

### Exams

* exam_id
* student_id
* course_id
* marks

## Analysis Performed

### Basic Queries

* Show all students
* Show students from Lucknow
* Show students older than 20
* Courses with fees greater than 10000

### Aggregate Analysis

* Average marks
* Highest marks
* Lowest marks
* Total students enrolled

### Grouping Analysis

* Number of students in each city
* Average marks by city
* Number of students in each course
* Courses having more than 2 students

### Join Operations

* Student name with course name
* Student name with marks
* Student name, course name and marks
* Students who have not taken exams

### Subquery Analysis

* Students scoring above average marks
* Courses above average fees
* Student enrolled in the most expensive course

### Advanced Analysis

* Top 5 students by marks
* Course generating highest revenue
* City with highest average marks
* Student enrolled in maximum courses
* Course with maximum students
